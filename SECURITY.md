# Security Policy

## Supported Versions

The latest version of Atik Business Hisab is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Atik Business Hisab, please report it privately through GitHub Security Advisories.

Please do not publicly disclose security vulnerabilities before they have been reviewed and addressed.

We will review valid security reports and take reasonable steps to protect users and business data.
